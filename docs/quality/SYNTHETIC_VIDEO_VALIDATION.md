## Deep Codec Verification (Deferred)

FFmpeg binary inspection (frame-exact FPS verification, corrupt_header actual unreadability test, real AAC decode) requires running FFmpeg during validation. This was not executed in R2. Deferred to a live environment with FFmpeg in PATH.

**Deferred checks:**
- Frame-by-frame FPS count for `dropped_frames` (expected 15 fps, not 30)
- Black frame verification for `stream_interrupt` at t=2.5s
- 3 weld event detection for `multi_spot_seq`
- `synth_unsupported_format.bin` rejection by video upload endpoint

## Isolation Guarantees

1. **No production database writes**: Generator writes only to `images/` and `videos/` output directories.
2. **No model training interference**: `SYNTHETIC_TEST_DATA=1` metadata ensures files are never ingested into E1-E4 training pipelines.
3. **Training gates unaffected**: E1-E4 conflict queue and 175 pending reviewer conflicts are unchanged.
4. **SHA256 integrity**: All files have checksums in MANIFEST.json.

## File Replay in LiveMonitoringPage

The LiveMonitoringPage accepts local video file paths for replay. Synthetic `.mp4` files can be used for:
- Testing the FILE REPLAY MODE banner appearance
- Verifying video stream handler accepts H.264/AAC input
- Stress-testing with `synth_stress_duration.mp4` (60s, 10.4 MB)

**NOT suitable for:**
- Proving real-time industrial camera performance
- Clearing E1-E4 training quality gates
- Any ground-truth defect detection claims
